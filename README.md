# 1C-Hotel-System (Отель «Точка останова»)

Учебная база 1С для второго итогового проекта на платформе Skillbox.
Автоматизация учёта в отеле: от бронирования номеров до расчёта зарплаты.

## 🏨 Что реализовано в проекте:

### 1. Учёт номерного фонда и бронирование
- Справочники: Номера, Услуги, Клиенты, Сотрудники.
- Документ «Бронирование» с табличными частями «Гости» и «Дополнительные услуги».
- Контроль занятости номеров через регистр сведений (по дням).
- Автоматический подбор цены номера и услуг из регистра цен (периодичность «День»).
- Автозаполнение менеджера при создании документа.

### 2. Выставление счёта и оплата
- Печатная форма счёта на оплату (БСП).
- Документ «Оплата» (возможна частичная оплата).
- Регистр накопления «ВзаиморасчетыСКлиентами» (Приход/Расход).
- Отчёт по задолженности/переплате клиентов.

### 3. Заказ дополнительных услуг
- Услуги выбираются непосредственно в документе «Бронирование».
- Стоимость услуг включается в общую сумму взаиморасчётов.

### 4. Расчёт зарплаты
- Документ «Начисление зарплаты» (Оклад, Премия, Отпуск, Больничный).
- Расчёт оклада по формуле: (Факт дни / План дни) * Ставка по должности.
- Графики работы (пятидневка, сутки через трое) в регистре сведений.
- Документ «Отражение зарплаты в бухучете» с проводками Дт 26 — Кт 70.

### 5. Права доступа
- Роль «Менеджер»: создание бронирований, просмотр оплат, нет доступа к зарплате.
- Роль «Бухгалтер»: создание оплат и зарплаты, просмотр бронирований.

## 📦 Как развернуть базу:
1. Скачайте файл `.dt` из этого репозитория (или из раздела Релизы).
2. Создайте новую пустую базу в 1С:Предприятие.
3. Откройте её в Конфигураторе.
4. Администрирование -> Загрузить информационную базу.
5. Выберите скачанный файл `.dt` и запустите 1С в режиме предприятия.
